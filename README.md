# Paper Companion

Paper Companion is a web platform for private or small-team paper analysis, organization, report generation, and narrated explainer video creation.

The project is planned as a public-access Next.js application backed by Supabase and local Ollama model services.

See [docs/PRD_ARCHITECTURE_ROADMAP.md](docs/PRD_ARCHITECTURE_ROADMAP.md) for the confirmed MVP scope, architecture, and development milestones.
